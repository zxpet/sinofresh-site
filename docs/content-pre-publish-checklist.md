# 文章发布前检查清单

> 用法：发布前逐项勾选；通用检查 13 项全过 + 对应类型检查全过才可发布。
> 详细规范见 `docs/content-sop.md`。

## 通用检查（所有类型）

□ H1 后是否有 TL;DR（3-5 条）？
□ H1 后是否有 Short Answer（40-80 字）？
□ 每个 H2 下第一句是否给结论？
□ 是否有 FAQ 区块（3-5 题）？
□ 正文是否有至少 2 处内链？
□ 锚文本是否用关键词（非 "Click here"）？
□ 内链是否包含 Pillar Page？
□ 标题是否匹配真实搜索问题？
□ 是否有 CTA 引导？
□ 封面图是否 16:9、1200×675 以上？
□ 分类是否正确（按 Pattern ↔ 分类对应表）？
□ Excerpt 是否手动填写（120-160 字）？
□ 元描述是否填写（150 字符以内）？

## 按类型检查

□ **Educational**：TL;DR + Short Answer + H2 问答 + FAQ
□ **Selection Guide**：对比表格 + 选型标准 + 常见错误
□ **Comparison**：A vs B 表格 + 适用场景 + 成本对比
□ **Case Study**：Client Profile + 挑战/方案/结果 + 客户原话
□ **Client Story**：客户原话 + 背景 + 结果 + 链接到 Case Study
□ **Technical**：技术原理 + 参数表 + QC 点
□ **Compliance**：标签要求 + 文件清单 + 市场对比
□ **Buyer's Guide**：评估标准 + 问题清单 + 避坑
□ **Market Trends**：市场数据 + 品类分析 + 区域洞察
□ **Thought Leadership**：观点 + 行业问题 + 我们的做法

## 数据真实性（Case Study / Client Story 附加）

□ 客户化名 + 国家口径是否与全站一致？
□ 数据点（MOQ / 周期 / 复购 / 评分）是否已确认可公开？
□ 客户原话是否来自真实反馈（或经客户同意的拟写）？
