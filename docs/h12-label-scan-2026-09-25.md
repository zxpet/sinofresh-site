# Label 白底白字 — 只读扫描报告（2026-09-25）

## 一、结论一句话

不是 FF 皮肤问题，也不是主题刻意设白——**是块模板的继承漏洞**：表单都坐在「深绿 section（`textColor:card-white`）→ 白卡 group（只设背景、没重置文字色）」里，label 的颜色 FF 没设、主题没设、FF 皮肤没设 ⇒ 一路继承 section 的白色。

## 二、三层排查（用户点名的三件事）

### 1. FF 外观皮肤设置

- `wp_fluentform_forms.appearance_settings` 5 个表单**全空**（NULL/空串）
- options 表无 fluentform 皮肤/主题类 option（只有无关的 global_modules_status）
- FF 免费版 CSS（`fluentform-public-default.css`）只给 label 设了 `display/font-weight/margin`，**无任何 color 规则**；`:root` 变量里也没有 label 色变量
- ⇒ FF 侧既不是白字的来源，也没有现成 UI 能改（Global Styles 属 Pro）；per-form 手动改 5 个表单也不管根因

### 2. 主题 CSS

- `style.css` 对 `.ff-el-input--label` 只设 `margin-bottom`（162 行），**无 color**
- 但已有同型先例：`.fluentform .ff-message-success` 被 pin 成深色（184 行，注释明说「sits on the white .sf-form-card — pin the dark body color so the message never lands light-on-white」）——**当时修了成功消息，漏了 label**
- theme.json 全局 body 文字色＝`text-primary`（深色 #1C2B24），被模板的白色文字覆盖后才出的问题

### 3. 根因（模板继承链）

`page-contact.html:18`（其余模板同型）：

```
section: backgroundColor:primary + textColor:card-white   ← 深绿底、白字（标题/导语，设计正确）
  └ group: backgroundColor:card-white                      ← 白卡，没设 textColor ⇒ 继承白字
      └ [fluentform id="8"]                                ← label 无色源 ⇒ 白底白字
```

## 三、影响面（5 个表单全中，共 13 页）

| 页面 | 表单 | 白色容器 |
|---|---|---|
| /contact/ ＋ 首页 ＋ 8 个剂型页 | 8 询盘 | `sf-form-card` / card-white group（×10 模板） |
| /services/ | 9 样品 | card-white group |
| /factory-tour/ | 10 参观 | card-white group |
| /quality/（**COA 弹窗内**） | 11 文件 | `.sf-certmodal__panel`（背景 card-white，同样没重置文字色，style.css 6422） |
| /feedback/ | 12 反馈 | `sf-form-card` |

访客看到的症状：只有红色必填星号和输入框，没有任何字段名（`aria-label` 兜底在，屏幕阅读器不受影响；输入框/下拉内的文字是 FF 自设深色，正常）。

## 四、修法对比

| 方案 | 改动 | 判断 |
|---|---|---|
| **A. 主题 CSS 一条规则（推荐）**：`.fluentform { color: var(--wp--preset--color--text-primary); }` | 1 处 | 全站 5 表单全部坐在白色表面上（卡/弹窗），pin 整个表单包装器的基础文字色 ⇒ label／描述／勾选文字／校验错误一并恢复继承深色；与既有 `.ff-message-success` pin 色先例同型；**cert modal 场景也一并覆盖** |
| B. 模板补 `textColor:"text-primary"` | 12 处模板 ＋ certmodal 仍要补 CSS | 修的是「卡忘重置色」，改动面大；modal 是纯 HTML 非 block，逃不掉 CSS |
| C. FF 皮肤设置 | 免费版无此 UI；per-form 手动 5 处 | 不治根，且未来新表单还会复发 |

**推荐 A**。附带说明：若未来出现「故意放在深色背景上的表单」，需为它单独覆写——当前不存在此场景。
