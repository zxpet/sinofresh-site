## 2. 口径、正文区定义与一致性核验

**正文区（region）定义**：本站是**全站编辑块主题，没有 `<main>`** —— 顶层容器只有 `.wp-site-blocks`。
所以正文区＝`<body>` 去掉 `<script>`/`<style>` 后再**减去页头页脚**（每页 `2×<header>` ＋ `2×<footer>`，**形状实测为常量**，工具会断言，不允许静默回退到整页）。
被丢弃的第三个口径：**整页去标签（含行内 CSS）** —— 本主题每页内联约 100 KB 块 CSS，每条 CSS 声明都算一个"词"，该口径偏高约 2.5 倍。
H5 扫描档曾用这个口径报 `/about/` 1,930 词 —— **本报告不复用该数**，只在本节说明它为何不可比。

同一个词数有两个算法，本报告**两个都报、严口径领衔**：
- **严口径**：只数 `h1-6 / p / li / td / th / dt / dd` 的文本 —— 访客读、爬虫称重的那部分；
- **宽口径**：正文区去标签后按空白切 —— 多出按钮文字、表单标签、图注等。

两种口径差约 1.09 倍。**排名一致性核验**：两侧排序偏移 >12 位的页 = **4** 个
⇒ **排序不一致**：本节的两个结论必须并列，不得挑好看的报。以下分类/排名表一律标口径；有 4 页在两种口径下位次相差 12 位以上。
