## 二、单行组头的设计定案（你要求报告里说明的点）

**问题**：Product Specifications 组缩为有值行后，20/21 帖只剩 Main Ingredients 一行——组头去留。

**定案＝都不选，改为「Main Ingredients 移入 Core Parameters，Product Specifications 组保留注册、空则不渲染」**（沿用现有 empty-means-absent 契约，组代码零特判）：

- **不选「保留组头」**：20 帖会呈现「标题＋一行」的失衡组，破坏参数表的网格秩序
- **不选「合并到 Core Parameters」**：理由同上但更彻底——如果指的是把 spec 组整个退役，那填内容阶段 weight/counts/shape/lifestage 填上后组就回不来了
- **实际方案的语义**：成分一览（前 3 项 chips）与 MOQ / 产地 / OEM 同属「采购一眼该知道的」，放 Core 组阅读流自然；全量成分本来就在下方 Formula & nutrition 带（pills）；Product Specifications 组保留给产品级结构化行（Unit Weight / Pack Size / Life Stage / Shape ＋ 3 个 OEM 能力字段），**一旦编辑填了这些字段，组自动回来**，无需再改代码
- **当前实际渲染**：多数帖只有一组 Core Parameters（7-8 行，双列均衡）；有结构化值的记录（如 158）呈两组
